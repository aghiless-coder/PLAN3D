# GARUDA Studio

Configurateur 3D de plans architecturaux avec rendu aquarelle translucide.

## Utilisation

Ouvrir `GARUDA-Studio.html` dans un navigateur moderne. L’application est autonome et permet de dessiner le terrain, les espaces, les niveaux et les éléments paysagers.

Le dossier `garuda-studio-source/` contient les sources JavaScript et HTML. `GARUDA-Studio-Guide.md` décrit les fonctions principales.
